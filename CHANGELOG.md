# Changelog

## 1.1.0 (2026-10-25)

### Added
- ModernFix: faster startup, lower memory use, many bug fixes
- FerriteCore: lower memory use
- ImmediatelyFast: faster HUD, text and map rendering
- Entity Culling: skips drawing entities and machines you can't see
- BadOptimizations: small client-side speedups (lighting, sky)

### Removed
- Distant Horizons
- Forgematica (Litematica port) and its library MaFgLib
- Personal files from the export: server list, schematics, minimap data, screenshots and unused menu assets.
  The pack is now about 10 MB instead of 53 MB

### Changed
- Default render distance is 12 chunks (was 30, which relied on Distant Horizons)

First public version (Gen 1).
